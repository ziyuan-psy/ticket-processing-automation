# 泛微联营商工单处理 SOP 摘要

来源：`泛微联营商工单处理SOP.pdf`

## 1. 招待券发放

人工路径：

- 企业微信 -> 工作台 -> 泛微工作台 -> 处理联营商工单。
- `admin.cotticoffee.com` 做具体操作。
- 用户营销平台 -> 卡券系统 -> 优惠券管理。
- 选择优惠券模板，复制模板标识。
- 用户营销平台 -> 营销系统 -> 活动管理。
- 搜索店名或 `招待*数量`，任一符合即可复制活动。
- 活动基础里填写活动名称。
- 奖品规则里选择优惠券模板和发放数量。
- 适用门店选择申请门店。
- 投放人群里填写或批量导入手机号。

本地可校验规则：

- 门店编号和门店名称必须都有值。
- 手机号必须都有值。
- 当前招待券固定使用优惠券模板标识 `CT20250521000001`，只需要根据工单变化发放数量。
- 活动名称必须为 `店名-招待*单个手机号发券数量`，例如 `新型金泉广场店-招待*60`。
- 单个手机号发放数量不能超过 100。
- 总量 = 单个手机号发放数量 * 手机号数量，不能超过 200。
- 复制现有活动时，需要清空旧门店、旧手机号，再写入新门店、新手机号。

SOP 截图中红色方框标出的内容均视为自动化必填/需修改字段：

- 活动名称：按 `店名-招待*数量` 自动填写。
- 选择奖品：优惠券模板固定为 `CT20250521000001`，发券数量按工单填写。
- 选择门店：按工单门店编号/门店名称查询并选择。
- 投放人群/手机号：按工单手机号填写；多个手机号走批量导入。

需要抓包确认的接口：

- 优惠券模板搜索/详情接口。
- 活动列表搜索接口。
- 复制活动接口。
- 活动详情接口。
- 活动保存接口。
- 门店搜索/选择接口。
- 手机号批量导入接口。
- 活动上架/发布/发放接口。

## 2. 优惠券发放

人工路径：

- 用户营销平台 -> 卡券系统 -> 优惠券管理。
- 选择模板，复制模板标识。
- 确认优惠券适用门店，使用外部导入。

本地可校验规则：

- 优惠券模板标识必须有值。
- 适用门店编号和名称必须都有值。

需要抓包确认的接口：

- 优惠券模板搜索/详情接口。
- 适用门店列表/查询接口。
- 适用门店外部导入接口。
- 券模板保存接口。
